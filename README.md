
[miniprojectREADME.md](https://github.com/user-attachments/files/18302857/miniprojectREADME.md)# **Celeste-Core**
Celeste-Core is a specialised hardware block dedicated to handle convolution operations. PicoRV32 RISC-V core is adopted as the processor, utilizing extensions such as multiplication, vector extension and division. It is implemented using the Fast Fourier Transform or FFT algorithm with a time complexity of O(NlogN). This operates on a kernel size of 8x8.

## Introduction:
Convolution is a mathematical operation that combines two functions (or signals) to produce a third function that expresses how the shape of one is modified by the other. Convolution is used in multiple processes including signal processing, image processing, machine learning models etc. In image processing, it's used for blurring, sharpening, edge detection, and feature extraction. In signal processing, it's used for filtering signals, noise reduction, and system analysis. In machine learning, particularly in convolutional neural networks (CNNs), where kernels learn to extract hierarchical features from images, enabling tasks like image classification, object detection, and image segmentation. 

2D convolution is fundamentally used for image processing, which extracts information from images. It involves sliding a small matrix of values, called a kernel or filter, over the input image. At each position, the kernel's values are multiplied element-wise with the corresponding pixel values in the image, and the results are summed to produce a single output pixel value. This process is repeated for every possible position of the kernel on the image, generating the convolved output image. The kernel's values determine the type of transformation or feature extraction performed.

Convolution usually involves multiple additions and multiplications to process a given input data and extract the required information. Multiplication in itself is a very expensive process in FPGA, and 2D convolution is a further resource-intensive process, requiring significant processing power and time. Processing high definition (HD), or even 4K images, involves millions of pixels, which require significant computational power for even basic operations like filtering or edge detection. Optimizing the performance of 2D convolution operations is critical for enhancing the efficiency of image processing, computer vision, and deep learning applications, particularly on systems with limited computational resources, as they face challenges in maintaining both speed and accuracy. 

In this project, we aim to design a separate hardware block for convolution with improved performance with respect to time efficiency, memory consumption and efficient usage of logic elements. 

## Project Objective:
The objective of this project is to build a hardware convolution block which performs the convolution operation under fewer multiplication cycles, while not affecting the normal operation of the ALU and ensuring gain in performance, while maintaining the same power consumption. To achieve the same, we plan to optimise the convolution process at all levels. By implementing pipelining and parallelism to handle the operations we will be using Fast Fourier transform convolution (FFT) which has a lower time complexity as opposed to traditional convolution algorithm. Designing the FFT block with a pipelined architecture to ensure multiple stages of FFT computation can execute in parallel, reducing bottlenecks. Implementing parallel processing using vector instructions to perform FFT on multiple data points simultaneously, optimizing performance.

## Algorithm:
Basic convolution, given by the Convolution theorem, computes the integral product of two functions namely the input signal and the kernel. In basic convolution algorithms, at higher dimensions, each dimension increases the degree of the algorithm polynomial linearly leading to expensive computation and increased time complexity. Thus, at higher dimensions, the convolution is often decomposed into lower dimension kernels and convolved step by step to reduce time complexity and memory requirement. To reduce the memory requirement of fast convolution, we involve DIF or decimation in frequency methodology which is implemented by the FFT algorithm. 

FFT reduces convolution’s arithmetic complexity by transforming the spatial domain into the frequency domain. By utilizing the convolution theorem, convolution becomes pointwise multiplication in the frequency domain. The frequency response of the filter is subsequently multiplied by the FFT of each of the zero-padded input segments, allowing for effective filtering in the frequency domain. Following this multiplication, an Inverse FFT is applied to convert the filtered frequency data back into the time domain. FFT is especially advantageous when working with large filters, where it provides substantial speedups. FFT based convolution utilizes the overlap-add method to efficiently process streaming data. 

A modified radix-4 FFT architecture is employed which significantly reduces hardware resource usage by sharing resources between the FFT and Inverse FFT blocks. Additionally, complex multiplication is further optimized by reducing the number of real multiplications required from four to three. This reduction not only minimizes hardware demands but also enhances computational efficiency. Fast Fourier transform convolution (FFT), has a time complexity of O(NlogN)  as opposed to conventional algorithm having a complexity of O(N2) and higher complexity as the dimensions increases.
